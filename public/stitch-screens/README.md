## Usage

These assets can be used as visual references and design inspiration for implementing the HRGSMS frontend. The HTML files contain the actual screen implementations from Stitch that can be examined for structure, styling, and component layout.

## Design System Reference

The SkyNest Hotel Management System uses the "Aura Premium Hospitality" design system with:
- **Primary Color:** #0F2A4A (Deep Sapphire Blue)
- **Secondary Color:** #FED65B (Champagne Gold)
- **Typography:** Playfair Display (headlines), Inter (body)
- **Theme:** Light mode with Glassmorphism effects
- **Spacing:** 8px unit base

## Integration Notes

These screens align well with the HRGSMS functionality:
- **Guest Services Management** maps to guest service requests and management
- **Management Reports & Billing** aligns with reporting and billing modules
- **Executive Dashboard** fits the manager/dashboard overview
- **Bookings & Availability** corresponds to the reservation/booking system

For implementation, consider using these as visual guides while building the actual React/Vite components in the HRGSMS frontend.
